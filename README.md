## 📖 About the Project

HomeServe is a web-based Home Services Booking Application designed to make household service booking simple and convenient.

Customers can explore different services, book professionals, select payment methods, and track their bookings. Admins can manage customer bookings, assign tasks to servers, and monitor service progress.

## 🚀 Features

### 👤 Customer
- Create an account and login.
- Explore available services.
- Search and filter services.
- Book home services.
- Select date and time slots.
- Choose payment methods.
- Track booking status.
- Cancel pending bookings.
- Submit ratings and reviews.

### 🛡️ Admin
- Admin login.
- Dashboard with booking statistics.
- Manage customer bookings.
- Manage registered servers.
- Assign tasks using Server IDs.
- Track task progress.
- Update booking status.
- Manage payment records.
- View customer feedback.

### 🔧 Server
- Server ID-based login.
- View assigned tasks.
- Access customer and service details.
- Start assigned work.
- Update task status.
- Complete assigned tasks.
